MODEL NOTES

Data & method

Inputs

Hourly 2027 apparent Sun and Earth azimuth/elevation from Skyfield, using JPL DE421, the NAIF lunar frame kernel and its DE421 orientation kernel. Site coordinates are approximate; observer height is 2 m.

Visibility

Power counts an hour when the Sun center elevation + 0.267° (solar angular radius) is above 0°. Earth link counts an hour when Earth center elevation is above 0°. Both use a flat horizon; terrain is not included.

Data limits

Coverage is 2027-01-01 00:00 through 2027-12-31 23:00 UTC. Results use hourly samples, so brief events between samples are not resolved. Coordinates and output are planning estimates, not navigation products.

Sources: NASA/JPL NAIF generic kernels · Skyfield
